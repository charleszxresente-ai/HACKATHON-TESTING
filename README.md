## Challenge Rules & Workflow

### 🚨 Branching Requirement
Do **NOT** commit your answers directly to the `main` branch. 

1. Create a new branch for each challenge using your name or team name:
   - Example: `feature/challenge-1-NAME`
   - Example: `feature/challenge-2-NAME`

---

## 📌 Challenge 1: Reverse Greeting Function
* **File:** `solution.py`
* **Goal:** Write a function that takes a text string, reverses it, and converts it to UPPERCASE.
* **Requirement:** Must be committed and pushed using a separate branch.

---

## 📌 Challenge 2: Array Sum & Pull Request Review
* **File:** `even_sum.py`
* **Goal:** Write a function that sums only the **even numbers** inside an array.
* **Requirement:** Must be submitted by opening a **Pull Request (PR)** from your branch into `main` for review.
